# 🧭 スタディコンパス（Study Compass）

答えを直接教えず、段階的なヒントで生徒が自力で気づけるように導く、中学生向けAI学習支援アプリ。

- **フェーズ1**: 定期テスト対策（教科書準拠レベル）
- **収録範囲**: 5教科（数学・英語・国語・理科・社会）× 中1範囲・約500問（数学は14単元×30問、他教科は10〜23問／単元。他学年は同じ設計で追加可能）

設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## 主な機能

| 機能 | 説明 |
|---|---|
| 3段階ヒント | 「わからない」ボタンで着眼点 → 解法の一部 → 答え直前まで、AI（Claude）が段階的に誘導。答えそのものは出さない |
| 写真でしつもん | ワークやプリントのわからない問題を撮影すると、AIが問題を読み取り同じ3段階方式でヒントを出す（`/camera`） |
| 正誤判定と解説 | 判定はアプリ側で決定論的に行い、AIは判定後の解説のみ生成（誤判定・誤答提示を防止） |
| 質問欄 | 問題についての自由質問。学習と無関係な話題は優しく学習に戻す（ガードレール） |
| 進捗記録 | どの段階までヒントを使ったかを解答ごとに記録 |
| 保護者ダッシュボード | 週次/月次で「取り組んだ教科」「ヒント使用率」「正答率の推移」を表示 |
| 決済（仕組みのみ） | Stripe月額サブスクリプション（Checkout + Webhook）。価格は後決め |

## セットアップ

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY を設定
npm run dev                  # http://localhost:3000
```

- `ANTHROPIC_API_KEY` 未設定でもアプリは動作します（AIヒントのみ無効、解説は静的解説にフォールバック）。
- Stripe関連の環境変数は任意です（未設定時、課金導線は「準備中」となります）。

## デプロイ（Netlify）

リポジトリをNetlifyに接続すれば `netlify.toml` の設定でそのままビルドされます。
環境変数（`ANTHROPIC_API_KEY` など）をNetlifyのダッシュボードで設定してください。

## 教科・学年の追加方法

1. `lib/problems/<subject>-grade<N>.ts` に問題データを追加し、`lib/problems/index.ts` に登録
2. `lib/prompts/<subject>.ts` に教科別プロンプト（学年別の範囲指定）を追加し、`lib/prompts/index.ts` に登録
3. `lib/subjects.ts` の該当教科を `implemented: true` に変更

UI・API・ダッシュボードは教科非依存のため変更不要です。

## 既知のMVP制約

- 進捗データはブラウザ（localStorage）保存。保護者画面は同一端末の記録を表示します。
  `lib/progress.ts` のインターフェースを維持したままDBバックエンドへ差し替え可能です。
- 認証は未実装（認証・DB・Stripe契約状態の紐づけは次フェーズ）。
